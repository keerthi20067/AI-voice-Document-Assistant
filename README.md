# AI Document Voice Assistant

## Description

AI Document Voice Assistant is an intelligent application that allows users to upload documents and interact with them using voice commands. The system converts speech to text, processes the query using AI, and provides voice-based responses.

## Features

* Upload and analyze documents
* Ask questions using voice input
* AI-powered document understanding
* Speech-to-text query processing
* Text-to-speech voice responses
* Interactive user interface

## Tech Stack

* Python
* Streamlit
* OpenAI API
* LangChain
* SpeechRecognition
* gTTS / Text-to-Speech
* FAISS (Vector Database)

## Installation

1. Clone the repository
   git clone https://github.com/yourusername/AI-Document-Voice-Assistant.git

2. Navigate to the project folder
   cd AI-Document-Voice-Assistant

3. Install dependencies
   pip install -r requirements.txt

4. Run the application
   streamlit run app.py
